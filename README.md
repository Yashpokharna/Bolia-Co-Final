## About the Project

**Bolia & Co.** is a professional Chartered Accountants firm website showcasing financial, accounting, auditing, and business consulting services.  
Built with **Next.js**, **Tailwind CSS**, and **GSAP**, it combines smooth animations with a clean, responsive UI.

🔗 **Live Website:** [https://bolia.netlify.app/](https://bolia.netlify.app/)

## Tech Stack

- [Next.js](https://nextjs.org/) – React framework for production-grade web apps  
- [Tailwind CSS](https://tailwindcss.com/) – Utility-first CSS for rapid styling  
- [GSAP](https://gsap.com/) – For rich animations and scroll-trigger effects  
- [Netlify](https://www.netlify.com/) – For hosting and CI/CD deployment
